# 🌌 Interactive Stargazer Sky Map

An advanced real-time astronomy visualization web application that allows users to explore stars, planets, and constellations directly from their browser. The project dynamically simulates the night sky based on geographical location, time, and celestial coordinate calculations, creating an immersive space exploration experience.

---

## ✨ Key Features

- 🌟 Real-time star rendering
- 🌌 Dynamic constellation mapping
- 🪐 Planet visualization system
- 📍 GPS-based live location detection
- 🔎 City search integration
- ⏳ Time Machine for past and future sky simulation
- 🌖 Moon phase tracking
- 🔭 Interactive zoom and drag controls
- 📱 Mobile touch gesture support
- 📚 Wikipedia-powered celestial information
- 🎨 Futuristic responsive UI design

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Canvas API
- OpenStreetMap API
- Wikipedia REST API

---

## ⚙️ How It Works

The application calculates celestial positions using astronomical coordinate systems such as Right Ascension (RA) and Declination (DEC). These coordinates are converted into Altitude-Azimuth positions based on the user's location and time, allowing the sky map to render visible celestial objects dynamically in real time.

Users can interact with the sky through zooming, panning, GPS location tracking, and time simulation controls for a complete virtual stargazing experience.
